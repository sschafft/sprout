## What Jetty does

Jetty runs AI workloads from plain-language instructions called runbooks. Each run gets a sandbox, a coding agent, a model, and the integrations it needs. You give it an objective and the criteria for success; it plans the steps, records every run, and scores the result with code checks, checklists, and judges, so a team can see which agent and model pairs do the job and where they fail.

It is built for teams who are past prompting and need to know whether an agent's output is good.
